# Cryptanalytic Model Extraction — Research Evolution Roadmap

This is a Chinese-language curated roadmap of **55 papers** on cryptanalytic neural-network model extraction, ordered by technical dependencies, bottlenecks, oracle assumptions, and research branches.

Start from the [Chinese README](README.md), [all papers](docs/papers.md), [evolution guide](docs/evolution.md), or [machine-readable data](data/papers.json).

This repository reorganizes the references from [springli07/awesome-cryptanalytic-extraction](https://github.com/springli07/awesome-cryptanalytic-extraction). It does not claim to have independently audited every citation relation or benchmark result.
